    <h1>Condition with looping programs</h1>

    <h2>Project Description </h2>
  </hr>
    <p>This project is based on TypeScript programs that demonstrate the use of different types of loops, including for, while, and do-while. The main objective of this project is to understand how loops work and how they can be used to perform repetitive tasks efficiently. It helps beginners develop their programming skills and improve their logical thinking through simple and practical examples.</p>
  </hr>
    <h2>What's included in this project </h2>
  </hr>
    <p>This project includes several programs based on loops and mathematical operations. It contains programs to print numbers in ascending and descending order, display even and odd numbers, calculate the sum of natural numbers and digits, and find the squares, cubes, and factorials of numbers. It also includes programs to print multiplication tables, generate the Fibonacci series, reverse a number, and count its digits.

Additionally, the project covers checking whether a number is prime, a palindrome, or an Armstrong number. It includes star and pyramid pattern printing using nested loops and a program to count the number of attempts needed to guess the correct number. These programs help demonstrate how loops and conditions work together to solve different problems.</p>
  </hr>
  <h2> How this project is made </h2>
  </hr>
  <p>This project is developed using TypeScript. First, the code for each program is written in a TypeScript file. The TypeScript code is then compiled into JavaScript so that it can run in a web browser. HTML can be used to connect the compiled JavaScript file with a webpage. Each program uses variables, operators, loops, and conditional statements to perform a particular task. The output is displayed in the browser's developer console.</p>
